# Polices des cartes météo

Fichiers officiels téléchargés depuis Google Fonts :

- Barlow Condensed (15 novembre 2026) : https://github.com/google/fonts/tree/main/ofl/barlowcondensed
  (SemiBold 600, Bold 700, ExtraBold 800).
- Montserrat (15 novembre 2026) : https://github.com/google/fonts/tree/main/ofl/montserrat
  (police variable, graisses 100 à 900).
- Inter 4.001 (26 novembre 2026) : https://github.com/google/fonts/tree/main/ofl/inter
  (police variable `Inter[opsz,wght].ttf`, graisses 100 à 900, chiffres tabulaires `tnum`, accents français).

Licences SIL Open Font License fournies dans `BarlowCondensed-OFL.txt`, `Montserrat-OFL.txt` et `Inter-OFL.txt`.
Polices hébergées localement (déclarées dans `src/app/globals.css`) :

- Barlow + Montserrat : variante « Méditerranée sauge : Barlow + Montserrat » des planches.
- Inter (famille `Inter Meteo`) : typographie « Facebook » des tableaux (Tab Val et Tableaux en JPG), lisible sur smartphone.
  Polices de secours si elle est indisponible : Segoe UI, polices système, Arial.
